# AbDotStore

Premium Indian software e-commerce store. React (Vite) + Supabase.

See **[documentation.md](./documentation.md)** for the full architecture, database
schema, environment variables, business flows, and the step-by-step guide for
transferring this project to the client's own Supabase account.

## Quick start

```bash
npm install
cp .env.example .env   # fill in values from your Supabase project (see documentation.md)
npm run dev
```
